# Автозапись звонков для Honor (MagicOS 10 / Android 16)

Готовый проект для автоматической записи входящих и исходящих звонков на нерутированных устройствах Honor под управлением MagicOS 10. **Android Studio не требуется** — APK можно собрать в облаке через GitHub Actions.

## Сборка APK через GitHub (без Android Studio)
1. Создайте новый репозиторий на GitHub (можно приватный).
2. Распакуйте этот архив и загрузите содержимое папки `MagicCallRecorder` в корень репозитория (через кнопку **Add file → Upload files** на сайте GitHub — обязательно загрузите и скрытую папку `.github/workflows/build-apk.yml`, либо перетащите всё содержимое папки в окно браузера).
3. Перейдите во вкладку **Actions** в репозитории — сборка **Build Android APK** запустится автоматически (или нажмите **Run workflow**).
4. Через 2–3 минуты откройте завершённый запуск и скачайте файл **`MagicCallRecorder-debug-apk`** в разделе **Artifacts** — внутри будет готовый `app-debug.apk`.

## Настройка на MagicOS 10 после установки APK
1. **Разрешение «Спецвозможностей» (Android 13–16 Restricted Settings):**
   Если при включении пункта *«Автозапись звонков (MagicOS)»* в **Настройки → Специальные возможности** система пишет *«В целях безопасности этот параметр сейчас недоступен»*:
   - Откройте **Настройки → Приложения → Приложения → Автозапись звонков**.
   - Нажмите на **три точки** в правом верхнем углу → **Разрешить настройки с ограничениями** (подтвердите отпечатком/PIN).
   - После этого включите службу в **Специальных возможностях**.
2. **Чтобы MagicOS 10 не выгружала приложение из памяти:**
   - В самом приложении нажмите **Отключить** напротив экономии батареи.
   - В **Настройки → Батарея → Запуск приложений** найдите **Автозапись звонков**, переключите на **Управление вручную** и оставьте включёнными все три пункта (*Автозапуск*, *Косвенный запуск*, *Работа в фоновом режиме*).

Записи сохраняются в формате `.m4a` в папку `Внутренняя память/Music/MagicCallRecorder`.
